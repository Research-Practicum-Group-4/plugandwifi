Acceptance criteria -- key user stories
Detailed acceptance criteria follow strict Gherkin syntax (Given / When / Then).
US-06 -- Location-based venue search
AC-1 (Happy path proximity search):
Given I am an authenticated or guest user loading the primary marketplace search interface, When I enter a valid target city name or explicit permission is granted to access my device's native browser coordinates,
Then the backend queries the location database and displays authorized workspace providers within a fixed 2km radius, prioritized nearest to farthest. AC-2 (Zero results out of bounds):
Given no active host venues exist within the designated boundaries,
When I trigger a location search query, Then the system outputs: "No workspace venues found within your current radius. Try manually expanding your search boundary or entering a different location."
AC-3 (Location access denied fallback): Given I deny browser access to coordinates,
When the discovery page finishes loading,
Then auto geo-query is blocked safely and a manual city/neighborhood entry box is shown.

AC-1 (Single attribute selection): Given I am looking at an active workspace feed list, When I check Verified , WiFi Then only venues with a verified Wi-Fi badge appear.
AC-2 (Multi-criteria combination): Given I am refining my focus constraints, When I select + + , WiFi Dedicated Plug Access Quiet Ambience Tier Then only venues matching all three constraints are surfaced.

AC-4 (State persistence): Given I applied filters and opened a venue detail page, When I click 'Back to Search', Then the previous filter + scroll state remains cached.
US-17 -- Core workspace booking execution
AC-1 (Successful path): Given I am logged in and selected an unreserved slot, When I click 'Confirm Booking', Then availability is validated, a booking row is created, the slot is marked taken, and a confirmation layout is shown.

US-23 -- Provider venue onboarding registration
AC-1 (Successful onboarding): Given I am logged in as a verified host and completed the form, When I submit, Then the system validates, writes to venues , geocodes the address, and makes the venue discoverable within 5 minutes.
