
Plug&Wifi -- Sprint plan
Sprint plan (8-week timeline)
The development cycle operates on a strict two-week sprint cadence spanning an 8-week delivery timeline (Sprints 1 through 4). Sprint 0 (Discovery, Ideation, and Initial Wireframing) is completed.
Sprint timeline & deliverables
Sprint 1 (Weeks 1­2) -- Data & Architecture Foundation
Focus: Technical setup, environment bootstrapping, CI pipeline deployment. No user-facing functional stories prioritized.
Deliverables: MySQL schema finalized/deployed; Flask API routing skeleton; React layout scaffold; seeded datasets prepared; mobile transaction flows diagrammed.
Sprint 2 (Weeks 3­4) -- Core End-to-End Booking Loop
Focus: Basic transaction pipeline, connecting client interfaces to DB entities. User stories: US-01, US-02, US-05, US-06, US-07, US-10, US-11, US-12, US13, US-14, US-17, US-18, US-23, US-24, US-28, US-29, US-32, US-33, US-35.
Deliverables: Registration/auth, venue search+filters, venue details, simulated booking, responsive UI, rule-based ranking live.
Sprint 3 (Weeks 5­6) -- Account, Persistence & Service Integration Focus: Expand user utilities, maps, ML quality checks.
User stories: US-03, US-08, US-09, US-19, US-20, US-25, US-26, US-30, US34. Deliverables: Reservation logs, cancellation, provider dashboards, maps integration, ML baseline validation report, payload verification.
