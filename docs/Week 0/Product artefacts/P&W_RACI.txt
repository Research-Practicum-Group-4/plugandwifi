
Plug&Wifi -- Team roles & RACI

Team roles & RACI matrix

Core team roles & responsibilities
1. Product & UX Lead Responsibilities: Owns scope, refines requirements, designs wireframes, design sign-off.
2. Scrum Master / Project Manager Responsibilities: Defines roles, sets up tools, manages p&p requests on Github facilitates ceremonies, tracks velocity, manages backlog, removes blockers.
3. Web Frontend Lead Responsibilities: Builds responsive React UI, state handling, component integration with APIs.
4. Backend & Database Lead Responsibilities: Flask logic, JWT auth, SQLAlchemy + MySQL schema, availability validation, mapping APIs.
5. Data & ML Lead Responsibilities: Seed data, suitability scoring (0­100), model evaluation vs baselines.
6. QA / Testing Lead Responsibilities: Automated tests, cross-platform verification, bug management, criteria validation.

RACI definitions
 R (Responsible): Executes the work  A (Accountable): Final sign-off / decision-making (one per activity)  C (Consulted): Provides input  I (Informed): Kept up to date
