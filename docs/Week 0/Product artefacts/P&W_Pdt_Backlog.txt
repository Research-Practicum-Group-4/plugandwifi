
Plug&Wifi -- Product backlog
Product backlog
Priority rankings utilize the strict MoSCoW framework:
 Must Have: Critical for the core MVP loop.  Should Have: High value, near-MVP requirement.  Could Have: Desirable stretch goal if velocity allows.  Won't Have: Out of scope for the current MVP release.
Epic 1: User Authentication & Account
 US-01 -- Register ( Must, 4h, S2) -- Account created, JWT issued, confirmation
displayed safely.
 US-02 -- Login ( Must, 3h, S2) -- Correct credentials grant access; wrong
inputs return a clear error.
 US-03 -- View/edit profile ( Should, 3h, S3) -- Name, email, and work
preferences are editable and saved to DB.
 US-04 -- Reset password ( Should, 4h, S3) -- Reset link sent within 60s; new
password accepted on next login.
 US-05 -- Logout ( Must, 1h, S2) -- JWT token invalidated; user immediately
redirected to landing page.
Epic 2: Venue Discovery & Search
 US-06 -- Location-based search ( Must, 6h, S2) -- Results within configurable
radius; sorted by proximity.
 US-07 -- Filters ( Must, 6h, S2) -- Filters apply correctly; results update
smoothly without page reload.
